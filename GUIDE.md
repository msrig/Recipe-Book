## 📚 Функции админ-панели:

### Главная страница (Dashboard)
- Статистика: количество рецептов, категорий, стран
- Быстрые действия: добавить рецепт, просмотреть все
- Управление категориями
- Список всех рецептов с редактированием/удалением

### Создание рецепта
1. Заполните название на русском и английском
2. Добавьте описание
3. Выберите категорию
4. Выберите страну происхождения
5. Добавьте ингредиенты (по одному)
6. Напишите инструкции приготовления
7. Загрузите фотографию
8. Нажмите "Создать рецепт"

### Редактирование рецепта
1. На главной странице админки нажмите кнопку редактирования (✏️) у рецепта
2. Или перейдите по ссылке: `/admin/edit-recipe.html?id=recipe_id`
3. Измените нужные поля
4. Загрузите новое изображение (опционально)
5. Нажмите "Сохранить изменения"
6. Или нажмите "Удалить рецепт" для удаления

## 🔌 API Endpoints

### Authentication
```
POST   /api/auth/login          # Вход в систему
GET    /api/auth/verify         # Проверка токена
```

### Recipes
```
GET    /api/recipes/            # Получить все (с фильтрацией)
GET    /api/recipes/{id}        # Получить один рецепт
POST   /api/recipes/            # Создать новый
PUT    /api/recipes/{id}        # Обновить рецепт
DELETE /api/recipes/{id}        # Удалить рецепт
POST   /api/recipes/{id}/image  # Загрузить изображение
```

### Categories & Countries
```
GET    /api/recipes/categories/list  # Все категории
POST   /api/recipes/categories/      # Добавить категорию
GET    /api/recipes/countries/list   # Все страны
```

## 🔐 Изменение пароля админа

Отредактируйте файл `backend/.env`:

```
ADMIN_USERNAME=admin
ADMIN_PASSWORD=ваш_новый_пароль
```

## 💡 Рекомендации:

1. **Первый запуск:** выполните `pip install -r backend/requirements.txt`
2. **Перезагрузка:** если изображения не загружаются, обновите страницу (Ctrl+F5)
3. **Безопасность:** измените пароль админа в production
4. **Резервная копия:** регулярно сохраняйте `backend/data/recipes.json`

---

## 📝 Примечания:

- Все рецепты сохраняются в `backend/data/recipes.json`
- Изображения сохраняются в папку `images/`
- Backend автоматически оптимизирует загружаемые изображения
- Поиск чувствителен к регистру только для английского текста (русский - нет)
- Фильтры можно комбинировать (поиск + категория + страна одновременно)
